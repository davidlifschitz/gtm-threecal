# ThreeCal

Paste a dump of dates. Get weekday, ISO week, Islamic, and Persian. Nothing is uploaded.

Ask this answers: [If you're an even slightly observant Muslim with an educated technical/professional life in many parts of the historical Persian speaking world, you have three calendars to keep track of](https://news.ycombinator.com/item?id=49372607)

- No account
- No upload
- Cap: 400 lines
- Gregorian in, table out
- Islamic uses the Kuwaiti civil algorithm (not a sighting)
- Persian uses Solar Hijri arithmetic

## Local

Open `index.html` in a browser, or:

```bash
python3 -m http.server 4173
```

This does not replace a local mosque or a Nowruz astronomer.
